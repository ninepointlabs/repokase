tonight's menu · eight courses

Kaiseki for repositories

No ordering, no tabs, no waiting on a browser. The chef brings it out in order.

  1. 先付01

    sakizuke Every repo on one counter

    Owned, collaborator and organization repositories in a single list. It opens instantly from a local cache and refreshes in the background. Sort by anything, filter by visibility, language, owner or health, and search across names, descriptions and topics.

    • instant from cache
    • every word must match
    • local categories
  2. 八寸02

    hassun Native to Omarchy

    A real desktop app, not a web view. It uses Wayland app ID repokase for your window rules, follows your system font, and adapts to Omarchy's half-screen tiles: list and details side by side when there's room, one at a time when there isn't.

    • class:repokase
    • keyboard first
    • F1 lists every shortcut
  3. 向付03

    mukozuke Clean cuts

    Edit descriptions and topics, archive and unarchive, flip visibility, transfer a repository to an organization or another account, or delete it. The irreversible ones open on Cancel and make you type the full name.

    • e · edit
    • Shift+A · archive
    • Shift+V · visibility
    • Shift+T · transfer

    Transfer mira-codes/pixel-forge

    CancelTransfer to studio-north

  4. 焼物04

    yakimono Straight off the grill: Actions

    Recent workflow runs for every repo. Re-run only the failed jobs, re-run or cancel a run, and start workflow_dispatch workflows from a form built from their inputs. Required inputs are checked before anything is sent.

    • re-run failed
    • cancel
    • run workflow…
  5. 煮物05

    nimono Slow-simmered traffic

    GitHub forgets views and clones after 14 days. Repokase records them daily into its own database, so the charts keep growing. An optional systemd user timer keeps recording on days you don't open the app.

    • views · clones · referrers
    • repokase-traffic.timer
  6. 酢の物06

    sunomono A sharp palate: health

    After every refresh, a few batched GraphQL requests check each repo, and the most serious problem shows up as a badge in the list.

    • CI failing
    • security
    • stale PRs
    • no README
    • no license
    • inactive
  7. 御飯07

    gohan The staples: bulk, categories, organizations

    Mark a handful of repos with x and archive them together or file them into a category. Organizations get their own place in the sidebar: one click narrows the list to an org and opens its people and settings.

    • x · mark
    • 1–9 · category
    • Ctrl+A · mark all
  8. 水物08

    mizumono Dessert: it wears your theme

    Run omarchy theme set and Repokase repaints on the spot with your palette, spacing and font. No restart. Try it on this page with the prompt at the top.

kitchen rules · what happens to your data

An open kitchen

  • Your token stays in the keyring

    Sign in with GitHub's device flow: Repokase never sees your password and has no client secret. The token lives only in the Secret Service keyring, never in a file or a log.

  • Only GitHub, nothing else

    Nothing is sent anywhere except github.com and api.github.com. No telemetry, no accounts, no server of ours.

  • Minimal permissions

    read:org, read:user, repo and workflow at sign-in. delete_repo only the first time you delete something, after Repokase explains why.

  • A cache you can throw away

    Repos, runs, categories and traffic live in one SQLite file under ~/.local/share/repokase. Delete it any time; the next refresh rebuilds what came from GitHub.

Install

From a release

A ready-built Arch package. pacman pulls the dependencies from the official repos.

sudo pacman -U https://github.com/ninepointlabs/repokase/releases/download/v0.2.5/repokase-0.2.5-1-any.pkg.tar.zst

From source

Builds the tagged release, checks its checksum and runs the tests.

git clone https://github.com/ninepointlabs/repokase
cd repokase/packaging
makepkg -si

Then

Launch Repokase from the app launcher, press Enter to sign in, and approve the code on GitHub. You need a Secret Service keyring: gnome-keyring ships with Omarchy.

Other Linux (AppImage)

For other distributions with glibc 2.34 or newer: Ubuntu 22.04, Debian 12, Fedora 39 and newer, on x86_64. Everything it needs is inside the file. Download repokase-0.2.5-x86_64.AppImage, then:

chmod +x repokase-0.2.5-x86_64.AppImage
./repokase-0.2.5-x86_64.AppImage
# add it to your app menu:
./repokase-0.2.5-x86_64.AppImage --install-desktop-entry

Or let Gear Lever or AppImageLauncher add it and keep it updated.
